# Deneme Uygulaması (Flask Blog)

Bu klasör, yerel model ve ajan testlerinde (kod analizi, veritabanı sorguları, hata ayıklama ve dosya düzenleme senaryoları) kullanılmak üzere hazırlanmış basit bir Flask + SQLite CRUD blog uygulamasıdır.

## Çalıştırma

```powershell
pip install -r requirements.txt
python app.py
```

Varsayılan olarak `http://127.0.0.1:5000` adresinde çalışır ve `blog.db` SQLite veritabanını otomatik olarak oluşturur.
